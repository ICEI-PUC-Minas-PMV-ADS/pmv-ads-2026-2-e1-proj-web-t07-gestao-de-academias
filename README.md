# Gestão de Academias

`Análise e Desenvolvimento de Sistemas`

`Desenvolvimento de Aplicação Web Front-End`

`2º Semestre de 2026 - Turma 07`

O projeto Gestão de Academias propõe uma aplicação web para organizar alunos, modalidades, instrutores e mensalidades de academias e escolas de artes marciais em um único ambiente administrativo.
