# Instruções de utilização

Esta pasta contém o código-fonte da aplicação **Gestão de Academias**.

## Estratégia de organização

Os artefatos de implementação devem ser organizados nesta pasta conforme as telas e funcionalidades desenvolvidas pelo grupo.

## Instalação do site

A aplicação será desenvolvida em HTML, CSS e JavaScript e poderá ser executada em navegador web.
